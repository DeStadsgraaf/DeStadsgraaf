# De Stadsgraaf Checklist

Gratis responsive webapp voor Opening, Closing en Schoonmaak.

## Huidige versie
- Werkt op Android, iPhone/iPad en Windows.
- Taken toevoegen, bewerken, verwijderen en afvinken.
- Zoek/filter.
- Dagelijkse reset van vinkstatus.
- Export/import van een JSON-back-up.
- PWA/service worker voor offline gebruik.
- Geen abonnement of betaalde API.

## Volgende stap
Supabase wordt als centrale database gekoppeld zodat alle vrijwilligers dezelfde taken en vinkstatus zien.
